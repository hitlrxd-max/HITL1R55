# منظومة سجل المدرسة

واجهة عربية RTL لإدارة طلاب مدرسة واحدة، والهيكل الدراسي، والحضور والغياب، والتقارير. تستخدم Next.js App Router وTypeScript وTailwind CSS وNeon PostgreSQL عبر Drizzle ORM.

## المتطلبات

- Node.js حديث.
- pnpm وفق النسخة المحددة في `package.json`.
- اتصال Neon يحتوي على متغير الخادم `DATABASE_URL`.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

افتح `http://localhost:3000`. لا تُضمّن `DATABASE_URL` في مكونات العميل أو أي متغير يبدأ بـ `NEXT_PUBLIC_`.

## Neon ومخطط البيانات

تتصل طبقة الخادم فقط بقاعدة Neon عبر `DATABASE_URL`. يحتوي المشروع على جدولين فقط:

- `school_structure`: السنوات الدراسية والصفوف والفصول وحالة السنة النشطة.
- `students`: بيانات الطالب، مرجع الهيكل الدراسي، وسجلات الحضور في `attendance_records` من نوع JSONB.

راجع `DATABASE.md` للتفاصيل وحدود تخزين الحضور داخل JSONB وخطة الترحيل المستقبلية. لا تستخدم أوامر حذف أو إعادة تهيئة على قاعدة الإنتاج. يجب فحص المخطط قبل أي ترقية.

## التحقق قبل النشر

```bash
pnpm exec tsc --noEmit
pnpm run build
```

يحتاج أمر البناء إلى `DATABASE_URL` متاحًا في بيئة التنفيذ. لا توجد حاليًا أداة lint مثبتة في المشروع؛ لذلك يجب إضافة إعداد ESLint رسمي قبل جعل فحص lint شرطًا آليًا.

## النشر على Vercel

1. اربط المستودع بمشروع Vercel.
2. أضف `DATABASE_URL` في Vercel ضمن بيئات Production وPreview وDevelopment حسب الحاجة.
3. لا تضع ملفات `.env*` في Git؛ القيم السرية تُدار من Vercel.
4. نفّذ البناء ثم راجع `/students` و`/structure` و`/attendance` و`/reports` بعد النشر.

## بيانات التجربة

لا يضيف المشروع بيانات تلقائية ولا يحتوي seed متصلًا بقاعدة الإنتاج. للاختبار، أضف سجلات من الواجهات أو استخدم قاعدة Neon منفصلة/فرعًا مخصصًا، ثم احذف بيانات الاختبار وفق سياسة البيئة.

## القيود الحالية

- جدولان فقط؛ لا توجد حسابات مدير أو معلمين أو أولياء أمور.
- لا توجد درجات أو تقارير دراسية.
- JSONB مناسب للمرحلة الحالية، لكن التعديلات المتزامنة على اليوم نفسه تعتمد على آخر كتابة. عند زيادة الحجم يُنقل الحضور إلى جدول مستقل بمفتاح فريد للطالب والتاريخ عبر ترحيل تدريجي.
- لا يُعد النشر مكتملًا إلا بعد نجاح اتصال Neon الفعلي واختبارات CRUD من بيئة Vercel.
